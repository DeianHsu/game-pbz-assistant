# 影之刃零 · 行前检查

**版本 1.2.0** · 64 位 Windows · Steam 版《影之刃零》

读取本机存档，查看推进主线前容易错过的任务和奖励、当前可以接取的任务、各地区缺少的收集品，以及成就的达成条件。

## 下载与使用

1. 下载 `PBZ-Quest-Guard-1.2.0-native-win-x64.exe`，双击运行。[1.2.0 发布页](https://github.com/DeianHsu/game-pbz-assistant/releases/tag/v1.2.0)
2. 游戏内至少保存一次。助手会自动找到 Steam 存档，打开「继续游戏」对应的槽位。可在窗口顶部切换账号和槽位。
3. 游戏再次保存后，点击 **重新读取存档** 或按 **F5** 同步进度。窗口底部显示所选槽位的保存时间。

助手使用 Windows 的 .NET Framework 4.x 系统组件。单个 EXE 即可离线运行，对本机游戏资源和存档只做读取。

## 功能与覆盖范围

支持 Steam 游戏构建 **26266538、26367565**。阶段识别覆盖悲泣溪谷、血色森林、陆家村、庞镇、梅谷湖、枷笼山、戏梦山庄、断魂山及通关后。正道大营等可提前探索的地区会结合存档中的到访记录判断。

| 页面 | 可以查什么 |
| --- | --- |
| **行前检查** | 21 组节点、84 项检查，包含分阶段复核。覆盖白赤练前的交付、少主丝带、七星剑阵与红衣女剑客、不灭侠胆六处遭遇、枷笼山救人、青蛇屋进山庄前、森林冰封回访和终局前复核。默认显示当前阶段待办，可单独查看「已失败或中断」，详情给出存档能确认的原因。 |
| **地图收集** | 按地区和类别查看铃铛、武器及影之武装、饰品及药瓶、挑战地点、杀气琥珀碎片、黑石碎片和记忆之花。按具体点位显示缺项，已核对的条目附附近铃铛、获取路线或前置条件。 |
| **全收集品** | 查找装备、书籍与篇章、花瓣、整花、珍宝和普通拾取点等。捡钱点显示意识尘埃金额，武器材料点显示材料种类和数量。支持地区、类别、状态和搜索筛选，可点击表头排序。 |
| **任务路线** | 按当前目的地分组，显示进行中的目标。接取判断覆盖 54 个任务，可切换「可接取但未接」，查看当前可接任务的人物或触发物、具体地点和附近铃铛。容易错过的任务会高亮。同一任务在同一地点且状态一致的目标合并显示，详情保留各条提示。 |
| **成就** | 查阅 66 项成就的达成要求、操作步骤和可读取的进度。默认显示「前置已满足」，可切换「暂不可取」「已解锁」或「全部成就」。持有所需武器即满足装备前置，招式等级要求见详情。 |
| **小张珍宝** | 按五个地区核对共 16 件珍宝。显示各区缺项和待交付状态，已交付的地区归入「已交付」。 |
| **资料来源** | 查看任务与收集路线所用的攻略。部分条目的详情也附对应页面。 |

以构建 **26367565** 为例，地图收集包含 9 个地图分组、528 个点位。全收集品另包含 1,211 处意识尘埃或武器材料拾取点，其中 661 处含意识尘埃、589 处含武器材料、39 处两者都有。

## 状态与使用边界

- **任务。** 「可接取」根据本周目到访、附近铃铛、剧情前置和已知截止事件判断。入口证据不足时，列表的覆盖范围会缩小。行前检查的断线原因以明确的日志或事件为准。部分对话选项、任务截止点和结局条件仍需在游戏中核对。
- **收集。** 「已知前置满足」表示已核对存档中的路线门槛。「本区流程收集」表示攻略将点位列在本区路线内，眼前通路仍需现场确认。「暂不可取」会说明缺少的条件，「解锁待核实」表示当前只能确认点位或缺项。部分门锁、书籍获取点和走法尚待核对。
- **普通拾取。** 金额按所选周目显示，有多种可能数量时会列出候选值。吊挂物有时只能从存档确认已被击落，是否拾取需在游戏中核对。
- **成就。** 解锁状态来自本机账号，前置条件按所选槽位判断。个别达成步骤仍待实机验证。

## 常见问题

- **找不到存档。** 确认游戏通过 Steam 安装，在游戏内保存一次后按 F5。
- **进度和游戏不同。** 检查窗口顶部的账号和槽位，以及底部保存时间。切换到旧槽位后，任务和收集进度会按该槽位显示，成就解锁仍读取账号记录。
- **提示版本未经验证。** 核对游戏的 Steam 构建编号。超出支持范围的构建需先完成存档与资源格式验证。
- **下载后出现安全提示。** 发布的 EXE 尚未签名。如被安全软件隔离，反馈时请附检测名称和文件路径。
