# 影之刃零 · 行前检查

**版本 1.2.1** · 64 位 Windows · Steam 版《影之刃零》

读取本机存档，查看推进主线前容易错过的任务和奖励、当前可以接取的任务、各地区缺少的收集品，以及成就的达成条件。

## 下载与使用

1. 安装 Steam 版《影之刃零》，并在游戏内至少保存一次。
2. 下载可执行文件后双击运行。[下载 Windows 64 位版](https://github.com/DeianHsu/game-pbz-assistant/releases/download/v1.2.1/PBZ-Quest-Guard-1.2.1-native-win-x64.exe) · [发布页](https://github.com/DeianHsu/game-pbz-assistant/releases/tag/v1.2.1)
3. 助手会自动打开游戏「继续游戏」对应的槽位。查看其他进度时，在窗口顶部切换账号和槽位。
4. 游戏再次保存后，点击 **重新读取存档** 或按 **F5** 更新进度。用窗口底部的保存时间确认读到了哪一份存档。

助手使用 Windows 的 .NET Framework 4.x 系统组件。单个 EXE 即可离线运行，对本机游戏资源和存档只做读取。

## 按用途查找

| 页面 | 怎么用 |
| --- | --- |
| **行前检查** | 推进主线、挑战首领或离开地区前，在游戏中保存并刷新助手。先看「当前待办」，点开条目查看截止节点和下一步。已断线的任务可在「已失败或中断」查看原因。 |
| **地图收集** | 选地区和类别，按点位核对铃铛、装备、碎片、记忆之花和挑战。选中条目可查附近铃铛和已核对的路线。回访时切换「全部点位」查看完整清单。 |
| **全收集品** | 可按名称搜索装备、书籍、花瓣、珍宝和拾取点，也可按地区、类别和状态筛选。想补铸魂时选择「已持有待铸魂」，点开装备查看材料与路线。意识尘埃和普通武器升级材料分别在「捡钱点」和「武器材料点」查看。 |
| **任务路线** | 用「当前目标」查看下一步的人物或触发点，用「可接取但未接」找附近的任务入口。「资源留档」可查仍留在游戏资源中的旧任务或当前版本存在流程冲突的任务。 |
| **成就** | 「前置已满足」适合按当前槽位找可以着手的成就。点开条目可查招式、等级要求和逐项进度。也可切换「暂不可取」「已解锁」和「全部成就」。 |
| **小张珍宝** | 按地区查看缺少哪些珍宝、哪一组可以交付，以及已经交付的地区。 |
| **资料来源** | 查看任务和收集路线所用的攻略。部分条目的详情也附有对应链接。 |

## 进度与状态

- **任务。** 「可接取」根据当前周目的到访、铃铛和已知剧情条件判断。地点或条件待核实时，查看条目详情并与游戏日志对照。
- **收集。** 地图页按点位核对，全收集品按物品归类。装备按基础形态统计，铸魂材料和合成部件分开。催心琵琶通过「幻术琵琶」任务修复。
- **路线。** 「已知前置满足」表示存档里有对应的前置记录。「本区流程收集」表示可沿详情中的区域路线寻找。「暂不可取」会列出缺少的条件，「解锁待核实」需要在游戏里确认。
- **普通拾取。** 金额按当前周目显示，有多种数量时会列出候选值。吊挂物若只记录了击落，拾取情况需要现场核对。
- **成就。** 解锁状态按本机账号读取，前置条件和可读取的进度按所选槽位判断。

## 常见问题

- **找不到存档。** 确认游戏通过 Steam 安装，在游戏内保存一次后按 F5。
- **进度和游戏不同。** 检查窗口顶部的账号和槽位，以及底部保存时间。切换到旧槽位后，任务和收集进度会按该槽位显示，成就解锁仍读取账号记录。
- **提示版本未经验证。** 本版支持 Steam 游戏构建 **26266538、26367565**。可在提示中核对本机的构建编号。
- **下载后出现安全提示。** 发布的 EXE 尚未签名。如被安全软件隔离，反馈时请附检测名称和文件路径。
